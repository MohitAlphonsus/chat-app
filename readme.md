# Chat-App 🚀

A real-time chat application built with React (frontend) and Express + Socket.io + MongoDB (backend), enabling user authentication and live messaging between users.

## Features

✅ User signup / login / authentication with JWT & cookies

✅ User profile management (profile picture upload, update)

✅ Fetch list of other users visible to the logged-in user

✅ Real-time messaging between users with Socket.io

✅ Storage of chat history in MongoDB

✅ Static frontend build served by backend (for production deployment)

✅ CORS & cookie-based authentication configured

✅ Secure password storage using bcrypt

Tech Stack

Frontend: React + Tailwind

Backend: NodeJS + Express + Socket.io

Database: MongoDB + Mongoose

Authentication: JWT + cookies

File storage (images): Cloudinary

### Getting Started

> Clone the repo

> Install dependencies in both server and client folders

> Setup .env variables (MongoDB URI, JWT secret, Cloudinary credentials)

> Run backend server + frontend, then sign up or login to chat
